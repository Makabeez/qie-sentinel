01 / POLICY FIREWALL

Untrusted instructions.
Enforced constraints.

An LLM may interpret a request or offer advice, but cannot set the authorization rules or bypass the vault. Every executable payment needs a scoped EIP-712 owner signature.

⌘

Recipient allowlist

Unknown recipient addresses are rejected by PolicyGuard, regardless of what an agent asks.

◷

Spending ceilings

One-transfer and daily QUSDC limits are checked on-chain, not entrusted to model output.

⊘

Replay protection

Unordered nonce bitmap and deadlines prevent reused or expired signed intents.

⚑

Emergency controls

Owner-only pause and unpause were exercised on QIE Mainnet. Recovery is implemented but has not been exercised in the displayed history.

Security disclosure

Hackathon prototype, not independently audited. The agent is not allowed to sign on behalf of the owner. The optional LLM advisor is non-authoritative. The public lab queries contract view functions and uses a block-timestamp comparison; it does not execute signed payment transactions. Individual RPC errors and unavailable responses are not counted as contract rejections. No wallet connection, API key, or private backend is hosted on this public site.
