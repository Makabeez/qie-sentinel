Operator handoff

Owner signature and executor transaction are performed only in a terminal, never by this web server. Use the proposal ID displayed in the queue.

python3 sentinel-agent/agent.py list
python3 sentinel-agent/agent.py approve PROPOSAL_ID
python3 sentinel-agent/agent.py execute PROPOSAL_ID

Live payments are real. Owner keystore stays outside the HTTP server. Explicit operator confirmation is required to submit.
